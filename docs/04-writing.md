# 04. Запись

## Конверт запроса

Тело `POST` и `PUT` – объект с одним ключом в единственном числе (camelCase), внутри которого лежат поля:

```
POST /api/lessons            {"lesson":     {...}}
POST /api/units              {"unit":       {...}}
POST /api/step-sources       {"stepSource": {...}}
PUT  /api/courses/<id>       {"course":     {...}}
PUT  /api/sections/<id>      {"section":    {...}}
PUT  /api/comments/<id>      {"comment":    {...}}
PUT  /api/course-reviews/<id> {"courseReview": {...}}
```

Ответ – как при чтении: список под ключом во множественном числе (`lessons[0]`). Удаление – `DELETE /api/<ресурс>/<id>`. Действия над объектом – `POST /api/<ресурс>/<id>/<действие>` с пустым телом `{}` (например, `announcements/<id>/send`).

## PUT – полным объектом

**Ожидание:** чтобы поменять описание курса, хватит `PUT` с одним полем `description`.
**На деле:** частичного обновления нет. На курсе и уроке без `title` запрос отбивается: `400 {"title": ["Обязательное поле."]}` (проверено в июле 2026).
**Что делать:** прочитайте объект, поменяйте нужные поля, отправьте целиком:

```python
lesson = get(f"/lessons/{lid}")["lessons"][0]
lesson["title"] = "Новое название"
put(f"/lessons/{lid}", {"lesson": lesson})
```

- Для `PUT /api/step-sources/<id>` достаточно `block`; надежнее отправлять вместе с ним `lesson`, `position` и остальные поля, прочитанные из шага.
- Привязку (`units`) и комментарий тоже обновляйте целиком: у комментария это `target`, `parent`, `text`, `thread`.
- Одно поле длиннее предела отклоняет весь `PUT`, вместе со всеми остальными полями запроса. Пределы – в [05-step-types.md](05-step-types.md#пределы-длины-полей).

## Создание курса

- Курс создается закрытым (`is_public: false`). Публикация в каталоге – ручное действие автора в интерфейсе Stepik, через API ее не делайте.
- С таким набором полей создание проходит без возражений валидатора:

```json
{"course": {"title": "Название", "is_public": false, "course_type": "basic", "is_paid": false,
            "is_certificate_with_score": false, "with_certificate": false,
            "is_self_paced": false, "is_enabled": false, "language": "ru"}}
```

**Ожидание:** описание курса можно передать сразу в `POST /api/courses`.
**На деле:** HTML в теле `POST /api/courses` защита Stepik принимает за атаку и отвечает "Access Blocked", а несколько таких запросов подряд закрывают доступ с IP на 5–10 минут.
**Что делать:** создайте курс без `description`, затем отправьте описание обычным `PUT /api/courses/<id>`. Подробно – [08-errors-and-limits.md](08-errors-and-limits.md#как-не-попасть-под-блокировку).

## Создание урока

**Ожидание:** урок, созданный через API, ведет себя как урок из редактора Stepik – виден только записанным на курс.
**На деле:** без явного поля урок создается **публичным** (проверено в июле 2026) и открывается по прямой ссылке любому человеку, даже не записанному на курс.
**Что делать:** всегда передавайте `is_public: false`. Уже созданные уроки проверьте: прочитайте их и поправьте `PUT`-ом.

Урок в модуле – это три запроса:

```
POST /api/lessons       {"lesson": {"title": "Урок", "is_public": false}}
POST /api/units         {"unit": {"section": SECTION_ID, "lesson": LESSON_ID, "position": 3}}
POST /api/step-sources  {"stepSource": {"lesson": LESSON_ID, "position": 1,
                         "block": {"name": "text", "text": "<p>Текст</p>"}}}
```

## Позиции: соседи не сдвигаются

**Ожидание:** `PUT /api/sections/<id>` с `position: 2` поставит модуль вторым, а остальные сдвинутся.
**На деле:** Stepik не трогает соседей. Если позицию 2 уже занимает другой модуль, у обоих будет 2, и порядок в программе станет случайным (проверено в августе 2026). С привязками уроков внутри модуля то же самое (сентябрь 2026): восемь уроков, созданных с `position: 1`, так и остались восемью первыми, и порядок в программе оказался произвольным.
**Что делать:** переставляя, перенумеруйте явно **все** модули курса (или все привязки модуля) одним проходом:

```python
for i, sid in enumerate(wanted_order, start=1):
    sec = get(f"/sections/{sid}")["sections"][0]
    sec["position"] = i
    put(f"/sections/{sid}", {"section": sec})
```

Потом перечитайте `course.sections` или `section.units` – они отсортированы по позиции – и сверьте с нужным порядком.

## Обложки и сертификат

- **Обложку курса через API не снять** (проверено в июле 2026): `PUT /api/courses/<id>` с `cover: null` отвечает 200 и ничего не меняет, `DELETE /api/course-images/<id>` – 405. Заменить можно: `PUT /api/course-images/<id>` формой `multipart/form-data` с полями `cover` (файл) и `id`.
- Тот же ресурс `course-images` принимает картинки сертификата: поля `certificate_cover_org` (логотип организации) и `certificate_footer` (подписи). Их, в отличие от обложки, пустое значение снимает (проверено в июле 2026).
- Обложку урока снять можно: `cover_url: null` в `PUT` урока.
- `is_certificate_auto_issued` меняется обычным `PUT` курса; `is_certificate_issued` – только для чтения, `PUT` его не меняет.
- Задание по умолчанию дает 1 балл. Баллы без включенного сертификата (`with_certificate` и порог `certificate_regular_threshold`) сертификата не дают.

## Настройки модуля

`grading_policy` через API только читается; `discounting_policy` (`no_discount`, `inverse`, `first_one`, `first_three`) записывается.

## Шаг: баллы и попытки

Баллы и ограничение попыток – поля шага, а не содержимого: `cost`, `max_submissions_count`, `has_submissions_restrictions` лежат рядом с `block`, а не внутри него.

```json
{"stepSource": {"lesson": 1, "position": 2, "cost": 1,
                "block": {"name": "string", "text": "<p>Вопрос</p>", "source": {...}}}}
```

## 201 Created не значит, что шаг работает

**Ожидание:** раз Stepik ответил 201, шаг готов.
**На деле:** исполняемые типы (`code`, `sql`, `dataset`, `math`, `random-tasks`) Stepik собирает асинхронно, уже после ответа. Через несколько секунд шаг получает `status`: `ready` или `error`, причина ошибки – в `reason_of_failure`. Сломанный шаг не создает попытку (`POST /api/attempts` → 400 "Quiz is not ready"): ученик не может его открыть, а автору никто не сообщает.
**Что делать:** после создания или правки подождите не меньше 10 секунд и прочитайте `GET /api/steps/<id>` (не `step-sources`). Все, что не `ready`, разбирайте по `reason_of_failure`. Типовые причины – в [05-step-types.md](05-step-types.md#исполняемые-типы).

## Перезапись урока целиком

- Если шаг того же типа стоит на той же позиции, правьте его `PUT`-ом, а не удаляйте и создавайте заново. Так у шага сохраняется id, а с ним ссылки на шаг.
- Если без пересоздания не обойтись, сначала создайте новые шаги, потом удалите старые: оборвется посередине – старое содержимое останется целым. Но обрыв между этими действиями оставляет **дубли**, и ученик читает один текст дважды. После любого прерванного или повторенного прогона сверьте число шагов в каждом уроке с ожидаемым.
- Перед тем как записать в курс текст из локальных файлов, сравните его с тем, что сейчас на Stepik. Запись затирает живой текст без предупреждения, а правки, сделанные прямо в редакторе Stepik, в файлах могут отсутствовать.
